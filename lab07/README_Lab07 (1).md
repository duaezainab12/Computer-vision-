# Improving HOG-Based Medical Image Classification Using a Genetic Algorithm

**Research question:** Can Genetic Algorithm (GA)-based feature selection improve the classification performance of HOG features while reducing feature dimensionality on medical images?

**Short answer (from the experiment below):** GA feature selection removed **43.1% of the HOG features** (8,100 → 4,611) and made SVM training about **2× faster**, with test performance **statistically indistinguishable from the baseline** (macro-F1 +0.36 pp, 95% CI [−0.44, +1.22], McNemar p = 0.56). It is a compression and speed benefit, not a proven accuracy gain.

This project compares a baseline **HOG + SVM (RBF)** classifier with a **GA-HOG + SVM (RBF)** classifier on BloodMNIST. It extends the Lab 05 pipeline (grayscale → HOG → SVM) and runs end to end in Google Colab.

`QUICK = True` in the config cell gives a faster trial run with a smaller GA.

## Method

| Step | Description |
|---|---|
| 1. Preprocessing | Grayscale, 128 × 128, fixed train / validation / test split, seed 42 |
| 2. HOG | 9 orientations, 8 × 8 pixels per cell, 2 × 2 cells per block, L2-Hys → 8,100 features |
| 3. Baseline | HOG + RBF-SVM, C / gamma / class weight tuned on the validation set |
| 4. GA | Chromosome = one bit per HOG feature (1 = keep) |
| 5. Fitness | `validation macro-F1 − α · (selected features / all features)`, α = 0.02 |
| 6. GA-HOG + SVM | RBF-SVM re-tuned on the selected features, trained on the full training set |
| 7. Evaluation | Test set used once, after all model selection was finished |

**GA operators:** random initial masks of varied density plus three seeded individuals (all features, top 50% and top 25% by ANOVA F-score); tournament selection (k = 3) with 2 elites; uniform crossover (p = 0.9); per-gene bit-flip mutation; repair keeps at least 100 features. For speed, fitness uses an exact precomputed RBF kernel on a stratified 2,500-image training subset; final models are trained on the full training set.

## Discussion

**Did GA feature selection improve performance?** Only marginally. On the test set, macro-F1 rose from 78.75% to 79.11% and balanced accuracy from 78.58% to 79.21%, but the bootstrap interval spans zero and McNemar's test gives p = 0.56, so these differences are within noise. The honest conclusion is that GA-HOG matched the baseline's accuracy while using 43.1% fewer features.

**Validation gain did not carry over.** Inside the GA (SVMs trained on a 2,500-image subset), validation macro-F1 rose from 0.718 (all features) to 0.753. With the final models trained on the full training set, validation macro-F1 was 80.21% for the baseline and 80.08% for GA-HOG, so the in-GA gain disappeared. This suggests the GA partly over-fitted the subset and validation set, and that selection helps less once there is more training data.

**Strengths.** The GA searched feature subsets jointly and traded accuracy for compactness through the penalty term. The smaller feature set roughly halved SVM training time (578 s → 290 s) and cut inference time per image by 43%. Even adding the 139 s GA search, GA search plus training (about 429 s) was shorter than baseline training alone (578 s), though the two used different hardware (GPU for the GA, CPU for the SVM fits). The feature map shows which image regions the GA kept.

**GA settings.** The larger population with higher mutation (GA-3) reached the best fitness (0.7413), versus 0.7399 for GA-2 and 0.7359 for GA-1. The smaller GA-1 removed the most features (54.8%) but at lower validation F1. Differences between settings are small and come from a single random seed.

**Per-class effects.** Monocyte (+1.01), lymphocyte (+0.89) and eosinophil (+0.48) improved most in F1, while immature granulocyte (−0.66) got slightly worse. The hardest classes for HOG remain monocyte (about 62% F1) and immature granulocyte (about 65% F1).

**Limitations.**
- The GA is stochastic and its fitness is measured on a single validation set, so the chosen subset can over-fit it.
- HOG is computed on grayscale images, so colour information, which is important for stained blood cells, is not used. This caps the accuracy of both models (about 79 to 80%).
- Only one random seed and one dataset split were run.
- The GA needs population × generations SVM trainings (442 for the selected setting). This is a one-off training-time cost, while the smaller feature set speeds up every later prediction.
